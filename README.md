# SpendSense – Smart Expense Tracker

SpendSense is a responsive personal expense-tracking web application that helps users record, manage, analyse, and monitor their daily expenses.

## Features

- **Expense Management:** Add, edit, and delete expenses.
- **Expense Summary:** View total spending, monthly spending, and expense count.
- **Category Analysis:** View spending grouped by expense category.
- **Search and Filters:** Search expenses and filter by category or month.
- **Sorting:** Sort expenses by date or amount.
- **Monthly Budget:** Set a monthly budget and monitor spending progress.
- **Data Persistence:** Save expense records using browser localStorage.
- **Dark and Light Mode:** Switch themes and retain the selected preference.
- **Visual Analytics:** View expense distribution through a chart.
- **Data Export:** Download expense records in CSV and JSON formats.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used

## How to Run the Project

1. Download or clone this repository.
2. Open the `SpendSense` folder in Visual Studio Code.
3. Open `index.html` using Live Server or Live Preview.
4. Start adding and managing your expenses.

## Data Storage

SpendSense uses browser localStorage to save expenses, budget settings, and theme preferences. Data remains available in the same browser unless its stored site data is cleared.
